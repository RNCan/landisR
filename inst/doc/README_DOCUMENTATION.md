# landisR beta.2 — Documentation map

Start here:

1. `QUICK_START.md` — installation and the three input routes.
2. `INPUTS.md` — conceptual input requirements and canonical directory format.
3. `INPUT_SCHEMA_VALIDATED_5KM.md` — exact table columns/classes generated from
   the validated 5 x 5 km reference.
4. `FUNCTION_REFERENCE.md` — public API and key arguments.
5. `VALIDATION.md` — scientific and package validation evidence.

The installed package also includes R help pages:

```r
?landisR
?landis_read
?landis_run
?landis_compare
```

Internal `bs52_*` functions are not part of the supported user API.
